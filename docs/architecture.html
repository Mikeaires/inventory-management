Demo Project Vue 3 FastAPI

Factory Inventory Management — System Architecture

Two-tier client-server demo for tracking inventory, orders, demand forecasts, and spending across multiple warehouses. Vue 3 SPA front end talks REST to a Python FastAPI backend serving in-memory mock data.

Data Flow — Example Request

End-to-end trace of GET /api/inventory?warehouse=Tokyo&category=Sensors

  1. User interaction in view component
    client/src/views/Inventory.vue
    User selects filters in FilterBar. onMounted() / change handler calls loadData().
  2. API client builds request
    client/src/api.js → getInventory(filters)
    Constructs query string and dispatches with Axios.
    const response = await axios.get(`${API_BASE_URL}/inventory?${params.toString()}`)
  3. HTTP request over the wire
    GET http://localhost:8001/api/inventory?warehouse=Tokyo&category=Sensors
    CORS middleware accepts the cross-origin request from the Vite dev server.
  4. FastAPI route handler
    server/main.py → get_inventory()
    @app.get("/api/inventory", response_model=List[InventoryItem])
def get_inventory(warehouse: Optional[str] = None,
                  category: Optional[str] = None):
    return apply_filters(inventory_items, warehouse, category)
  5. Filter against in-memory data
    server/main.py → apply_filters()  •  server/mock_data.py
    List comprehension filters inventory_items loaded from server/data/inventory.json at startup.
  6. Pydantic validation & JSON response
    InventoryItem(BaseModel)
    FastAPI validates each item against the response model and serializes to JSON.
  7. Client updates reactive state
    Inventory.vue → ref & computed
    The inventoryItems ref is reassigned; filteredItems recomputes and the table re-renders.

Domain Entities

Inventory Item
SKU, warehouse, quantity on hand, reorder point, unit cost.
Order
Customer, items, status (Delivered / Shipped / Processing / Backordered), value.
Demand Forecast
Current vs forecasted demand per SKU, trend direction.
Backlog Item
Unfulfilled need, qty short, days delayed, priority, PO link.
Purchase Order
Supplier, quantity, unit cost, expected delivery, status.
Spending
Procurement / operational / labor / overhead, monthly & YTD.
Transaction
Recent line-item costs categorized for reporting.
